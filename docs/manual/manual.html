1. 這是什麼

我們是一群大約 20 位的整理師。整理工作通常要兩人以上才能出班，不管誰接到案子，都是在這群彼此信任的夥伴裡互相找人。

以前找人要一個一個開 LINE 對話框問、等回覆、再跟客戶來回對時間。小火柴把這件事變成：

  • 打開月曆，就看到每一天還能約到幾個人。
  • 火柴排好想邀的人和順位，系統自動用 LINE 邀請，有人婉拒就自動找下一位。
  • 在 LINE 私下談好的，也能一步記進 App，月曆永遠是準的。
  • 所有人的畫面即時同步。

小火柴是減少彼此動作數的工具，不是規則。它不決定任何事，只負責把大家決定好的事記下來、通知到。

2. 女孩怎麼用

每月填班

每月 20 號前填好下個月。每一天點一下就切換：

狀態意思影響
沒空沒點的日子，就是沒空不會出現在「有空」名單，但火柴仍然可以邀你
有空可以出班算進月曆的「還能約」
野放在別處工作、出去玩，不太能看手機這天收到邀請，倒數等到 18:00 才開始。邀請你的火柴看得到你在野放；月曆上其他夥伴看到的是「沒空」
  • 可以按「沿用上月習慣」一鍵帶入上個月的模式，再微調。
  • 隨時都能修改。臨時接到別的工作，回月曆把那天改成野放就好。

收到邀請

  • 邀請會送到 LINE，卡片上有日期、時間、區域、案件類型和給你的時薪。
  • 按「確認出班」才算數；按「婉拒」不用理由。
  • 同一天可能收到好幾張邀請，確認哪一張就是哪一張，其他邀請會自動關閉。
  • 倒數結束不代表沒機會了：只要那天還沒額滿，你仍然可以確認。
  • 點 LINE 裡的連結就會打開小火柴，自動登入。

取消已確認的班

  • 在「我的班」按取消，選一個原因：有更重要的安排或身體不適。火柴會立刻收到通知，系統同時開始補位。
  • 如果你已經找到人代班，請直接跟火柴說，讓火柴用「替換」處理（見第 4 章）。
  • 出班前 3 天內取消，畫面會提醒你也直接打給火柴說一聲。

案件有變動時

火柴修改案件時，你會收到 LINE 通知。需要你回應的情況請見第 4 章。

3. 火柴怎麼用

什麼時候點燃

接到案子就可以點燃，不一定要等客戶付款。先把女孩約好，跟客戶談的時候更有底氣；案子沒成就熄滅，或減少人數。

點燃很自由，但請記得：每一次熄滅，都代表有人替你空出了一天。

出班日期可以選多天

區域（必填）例如「中山區」。邀請卡和月曆上顯示這一格。
詳細地址（選填）只有確認出班的人看得到。填了，布達訊息會自動帶入；不填，就在群組裡講。

我也出班？

打開（預設）：火柴也是女孩之一關掉：火柴只負責接洽
人數填「總共幾人（含我）」。填 3，系統只邀 2 位。火柴不算在內，填 3 就邀 3 位。
火柴自己自動算已確認，不用邀請自己。那天的有空不受影響，還能去當別根火柴的女孩。

排順位

  • 名單上有所有成員。標了有空的排在上面；沒標的在「其他成員」，按「＋ 加入順位」一樣可以邀請。
  • 那天已經有別人的班的人，會顯示灰色、不能選。
  • 依你心中的順序排，例如需要 2 人，可以排 5 個。系統只先邀前面剛好需要的人數，候補的人不會被打擾。
  • 已經在 LINE 談好的人，按她名字下的「直接加入」，就直接算已確認，她只會收到通知。
  • 時薪會帶入你上次和她合作的金額。第一次合作要填一次。

鄰家女孩

團隊裡找不到人時，火柴可以自己找外面的人來幫忙。在順位下方輸入名字，按「＋ 鄰家女孩」：

  • 直接算進人數，系統要邀請的人數會自動減少；如果多出來，還在等回覆的邀請會從順位最後開始撤回。
  • 她不需要帳號，也不會收到任何通知，細節由火柴在群組裡講。布達訊息會列出她的名字。
  • 時薪可填可不填，只有火柴和管理者看得到。
  • 案件頁也可以隨時加入或移除。移除後，系統會照順位補位。

急件

打開「急件：同時邀請全部候補」，就會一次邀請名單上所有人，先確認的人先拿到，額滿後其他人收到「已額滿」。適合明天就要人的情況。

回覆時間

距離出班日倒數多久後，也開始邀下一位
超過一週12 小時
3–7 天4 小時
3 天內2 小時

對方當天出班中或野放，倒數等到 18:00 才開始；22:00 到隔天 08:00 也不倒數。等不及就用急件。

送出之後

  • 在「我的火柴」看每一天的進度：誰確認、誰婉拒、誰還在倒數。
  • 人數滿了會收到 LINE 通知。
  • 自己建一個 LINE 群組，再按「分享布達訊息」，App 會把案件資訊整理好，讓你直接傳進群組。（LINE 不允許 App 自動建群組，所以這一步由火柴完成。）

6. 為什麼這樣設計

App 只把能自動化的事做好，不擋任何事。其他的，我們相信彼此的判斷。

為什麼「沒點」就當作沒空？

這樣月曆上的人數才準。估價時最怕看到有人，結果其實約不到。忘記填只會讓你少出現在名單上，火柴還是邀得到你。

為什麼要分「沒空」和「野放」？

沒空的人可能只是休假，手機照樣看得到；野放的人是真的回不了。分開之後，倒數暫停只用在真的需要的人身上，不會讓每張邀請都變慢，也不會讓在忙的人因為晚回而錯過。

為什麼同一天可以收到好幾張邀請？

做這個 App 的初衷，是盡可能排滿每個人的時間。多收到幾個機會，對女孩是好事；由她自己選，也最單純。

為什麼倒數結束後，人還是可以確認？

倒數的用意是不讓案子卡住，而不是淘汰人。時間到了，系統就同時多問一位；只要還沒額滿，誰先確認誰拿到。

為什麼可以邀沒標有空的人，還可以直接加入？

對方可能只是忘了填，也可能願意為了你的邀請調整行程。大家本來就會在 LINE 私下談，App 攔不住，也不該攔。重點是談好之後只要一步就能記進來，月曆才會一直是準的。

為什麼已有班的人不能選？

同一天被兩根火柴搶同一個人，只會造成紛爭。要調動已確認的班，請先跟原本的火柴談，再由她用「替換」或讓女孩取消。

為什麼可以先點燃再跟客戶談，而且沒有限制？

真正讓日期確定的是客戶付款，這件事發生在 App 之外。先把人約好，談案時更有把握。但被你邀請的女孩，是替你空出了一天；如果經常熄滅，女孩自然會對你的邀請比較保留。這不需要規則，大家心裡都有數。

為什麼取消不需要火柴同意，也沒有懲罰？

能進這個團隊的夥伴，加入時就已經把關過了。取消本身就會降低大家對你的信任，有分寸的夥伴不會輕易這麼做。所以 App 只做兩件事：讓火柴立刻知道，並且馬上補位。

為什麼婉拒不用理由，取消卻要選原因？

婉拒時還沒答應，不欠任何人解釋。取消是答應之後反悔，火柴需要知道發生了什麼事。原因只有兩個選項，點一下就好。

為什麼缺人只提醒，不自動改成急件？

火柴排的順位是她的判斷，自動改成急件會打擾到她原本不想先找的人。提醒附上「改成急件」按鈕，要不要按，由火柴決定。

為什麼鄰家女孩不收通知、也不算進團隊統計？

她不是團隊成員，沒有帳號，也不需要用 App。月報裡的對帳和表現指標，看的是團隊夥伴之間的合作，所以只算團隊成員。

為什麼 App 不分資歷或專長？

每個人適合什麼案子，火柴們心裡都清楚。順位就是火柴的判斷。

以下是概念圖，名字、地址、時薪都是示意，實際畫面會依大家的回饋調整。

3 點燃火柴

填日期、時間、區域（詳細地址選填）、案件類型。在「每天的人手」設定這天是否「我也出班」、總人數、是否急件，再依順位排女孩。

誰確認、誰婉拒後被自動補位、誰還在倒數，一目了然。有人代班按「替換」，客戶有變動按「修改案件」。

附錄：管理者

這一章給 Robert 和備援管理者。

管理功能

  • 核准夥伴：新夥伴用 LINE 登入後，要經過核准才能使用。
  • 修改任何資料，並查看修改紀錄。
  • 重新綁定：夥伴換手機或換 LINE 帳號時，把班表和紀錄接回新帳號。
  • 暫停夥伴：受傷、出國等期間，暫時不會出現在名單裡，也不會收到填班提醒。
  • 颱風延期：一鍵把某天所有案件標成延期，並通知所有相關的人。
  • LINE 訊息用量：看本月用了多少則。接近上限時，非邀請類的通知自動改用網頁推播。

至少讓一位夥伴擁有管理者權限，並知道 App 出問題時找誰、怎麼暫時改回 LINE 群組找人。資料設定自動備份。

開發順序

  1. 準備：夥伴看過概念圖和說明書；申請 LINE 官方帳號（開通訊息 API 和 LIFF）與 Supabase。
  2. 第一版：LINE 登入與核准、月曆（有空／野放）、點燃（含我也出班、區域與詳細地址）、排順位、邀請與直接加入、急件、LINE 邀請與確認、自動補位與倒數、撞期提醒、取消、修改案件、替換、鄰家女孩、缺人提醒與開工、熄滅、分享布達訊息。
  3. 第二版：管理者功能、月報、颱風延期、訊息用量與網頁推播。
