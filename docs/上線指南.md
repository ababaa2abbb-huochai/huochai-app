# 賣女孩的小火柴：上線指南

這份指南寫給 Robert。需要你親自做的步驟只有「申請帳號、複製金鑰」，其他部分可以交給 Claude 處理。
畫面上的按鈕名稱可能隨各平台改版而不同。照著做時，把你看到的畫面貼給 Claude，就能一步一步帶你完成。

---

## 你需要準備的東西

| 項目 | 用途 | 費用 |
|---|---|---|
| LINE 官方帳號（Messaging API） | 送邀請、處理「確認／婉拒」按鈕 | 輕用量 0 元（每月 200 則） |
| LINE Login 頻道＋LIFF | 夥伴從 LINE 打開小火柴、自動登入 | 免費 |
| Supabase 專案 | 存資料、即時同步、每分鐘跑排班規則 | 免費方案 |
| robertya.com | 放 App 的畫面（一個 index.html） | 現有主機 |

---

## 第 1 步：建立 Supabase 專案

1. 到 supabase.com 註冊，建立新專案。地區選 **Northeast Asia (Tokyo)** 或 **Southeast Asia (Singapore)**，離台灣比較近。
2. 建好後，到專案設定（Project Settings）的 **API**，記下這幾個值：
   - Project URL（例如 `https://xxxx.supabase.co`）
   - `anon` public key
   - `service_role` key（這把是**最高權限**，不要給別人，也不要放進網頁）
   - **JWT Secret**（在 JWT 相關設定裡，可能標示為 Legacy JWT secret）

> 如果你的專案找不到 JWT Secret，把畫面截圖給 Claude。新版 Supabase 有改用另一種簽章方式的可能，登入的部分要跟著調整。

## 第 2 步：建立 LINE 官方帳號與 Messaging API

1. 到 LINE Official Account Manager 建立官方帳號，名稱例如「小火柴」，方案選**輕用量**。
2. 在官方帳號的設定裡**啟用 Messaging API**，這時會要求你建立或選擇一個「Provider」（提供者），名稱可以填「知形合衣」或團隊名稱。
3. 到 LINE Developers 後台，打開這個 Messaging API 頻道，記下：
   - **Channel secret**
   - **Channel access token**（長期的，按「Issue」產生）
4. 回應設定：關閉「自動回應訊息」，開啟「Webhook」。

## 第 3 步：建立 LINE Login 頻道與 LIFF

1. 在 LINE Developers **同一個 Provider** 底下，新增一個 **LINE Login** 頻道。
2. 記下這個頻道的 **Channel ID**。
3. 在這個頻道的 **LIFF** 分頁新增一個 LIFF App：
   - Size：**Full**
   - Endpoint URL：`https://robertya.com/huochai/`（之後放 App 的網址）
   - Scope：勾選 `openid`、`profile`
   - Add friend option：選 **On (Aggressive)**，夥伴第一次打開時會被引導加官方帳號好友，這樣才收得到邀請
4. 記下 **LIFF ID**（長得像 `1234567890-AbCdEfGh`）。
5. 在 LINE Login 頻道設定裡，把它和官方帳號連結（Linked OA / bot link），選第 2 步建立的官方帳號。

## 第 4 步：把金鑰交給 Claude

把下面這些值整理好，在對話裡貼給 Claude。`service_role` key、Channel secret、access token、JWT Secret 這四個請**只在私人對話裡給**，不要貼到群組。

```
SUPABASE_URL=
SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
SUPABASE_JWT_SECRET=
LINE_CHANNEL_SECRET=
LINE_CHANNEL_ACCESS_TOKEN=
LINE_LOGIN_CHANNEL_ID=
LIFF_ID=
```

Claude 接下來會做這些事：

- 把資料庫結構和排班規則裝進 Supabase（`supabase/migrations/` 裡的 5 個檔案）
- 部署三個伺服器程式：`line-login`（登入）、`line-notify`（送邀請）、`line-webhook`（處理確認／婉拒按鈕）
- 設定每分鐘的排程：跑倒數與提醒，並送出 LINE 邀請
- 產生正式版的 `index.html`

## 第 5 步：把 Webhook 網址填回 LINE

在 Messaging API 頻道的 Webhook URL 填入：

```
https://你的專案.supabase.co/functions/v1/line-webhook
```

按「Verify」確認成功。

## 第 6 步：上傳到 robertya.com

和「衣目了然」的流程一樣：

1. 用 WP File Manager 在網站根目錄建立資料夾 `huochai`
2. 上傳 Claude 給你的 `index.html`
3. 清除 Varnish 快取
4. 用手機 LINE 打開 `https://liff.line.me/你的LIFF_ID`，確認能登入

## 第 7 步：邀請夥伴

1. 你是第一個登入的人，會自動成為**管理者**。
2. 把 `https://liff.line.me/你的LIFF_ID` 傳到夥伴群組，大家點開、登入、加官方帳號好友。
3. 新夥伴登入後是「等待核准」，你在「管理」頁按**核准**即可。
4. 請大家在**填班**頁把下個月有空的日子標好。

## 費用監控

- 輕用量每月 200 則推播。只有「邀請」和「時間變更」會用到推播；確認／婉拒按鈕的回覆用的是回覆訊息，不算在額度裡。
- 如果月中額度用完，LINE 會擋下推播，但 App 裡的鈴鐺通知照常。可以在 Supabase 的 `notifications` 表看 `send_error` 欄位。
- 常常不夠用時，升級中用量（2026/11/1 起每月 1,000 元，3,000 則）。

## 出問題時

- **夥伴說收不到邀請**：請她確認有加官方帳號好友、沒有封鎖。App 裡的「我的班」照樣看得到邀請。
- **App 打不開**：暫時改回在 LINE 群組喊人，再找 Claude 或備援管理者處理。
- **資料備份**：Supabase 免費方案沒有自動每日備份。建議每月在 Supabase 後台匯出一次，或升級 Pro（約 US$25／月）。
