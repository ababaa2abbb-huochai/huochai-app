賣女孩的小火柴

夥伴 5 分鐘上手指南

在做什麼名詞第一次登入填班 收到邀請我的班當火柴常見問題

這是什麼？

以前接到整理案，要在群組喊「誰 11/8 有空？」，再一個一個私訊、等回覆、算人數。

小火柴把這件事變簡單：

  1. 大家每個月先在小火柴標好哪幾天有空。
  2. 接到案子的人「點一根火柴」：選日期、要幾個人、想找誰。
  3. 系統照順序幫你發邀請，被邀請的人在 LINE 收到邀請卡，按一下就確認。
  4. 有人婉拒或沒回，系統自動邀請下一位，直到人數湊滿。
一句話：標好有空 → 等邀請 → 按確認。大部分時候你只需要做這三件事。

1第一次登入

  1. 在 LINE 裡點群組裡的小火柴連結。不要複製到 Safari 或 Chrome 開。
  2. 跳出「小火柴要取得你的資料」→ 按許可。
  3. 跳出加好友 → 一定要加「賣女孩的小火柴」好友。
    沒加好友就收不到邀請卡。
  4. 看到「還沒開通」→ 等管理者核准，通常一分鐘內畫面會自動進到 App。
以後要打開小火柴：在 LINE 打開「賣女孩的小火柴」聊天室，按下方的橘色大按鈕就好。

2填班：標好有空的日子

點下方的「填班」，每天點一下就會切換：

沒空→有空→野放→ 回到沒空
  • 點了就自動存，不用按送出。
  • 請在每月 20 號前標好下個月。
  • 每個月習慣差不多？按「沿用上個月」一次搞定。
野放的日子，其他夥伴看到的是「沒空」，只有邀請你的火柴知道你在野放、會回得比較晚。那天收到邀請，倒數會等到晚上 18:00 才開始。

月曆上每一格的數字＝那天還能約到幾個人，顏色越深人越多。

3收到邀請

LINE 會跳出一張橘色邀請卡，上面有日期、時間、區域、類型和時薪。直接按：

  • 確認出班：這班就是你的了。
  • 婉拒：系統會去邀請下一位，不用不好意思。

要在多久內回覆？

距離出班日回覆時間
一週以上12 小時
3–7 天4 小時
3 天內2 小時
  • 晚上 22:00 到早上 08:00 不倒數，安心睡覺。
  • 超過時間沒回，系統會邀請下一位。但只要那天還沒額滿，你晚點按確認還是有效。
  • 先確認的人先拿到。額滿了再按，會收到「已經額滿」的回覆。
時薪只有你和火柴看得到，其他夥伴看不到。

4我的班

點下方的「我的班」，可以看到：

  • 等你回覆的邀請，在這裡也能確認或婉拒。
  • 接下來的班：時間、地址、同組有誰。地址只有確認出班的人看得到。

火柴改了時間

會問你「新時間可以嗎？」→ 按沒問題或沒辦法。不回覆就維持原班。

臨時不能去

  • 按「取消這個班」，選原因。火柴會馬上收到通知，系統也會自動找人補位。
  • 已經找好人代班？直接跟火柴說，請火柴用「代班」把位子交接過去。
  • 出班前 3 天內取消，請也打電話跟火柴說一聲。

5當火柴：自己接案找人

接到案子時，按下方中間的「點火柴」：

  1. 填時間、區域、類型、地址。
  2. 選日期和每天要幾個人，自己也要出班就打開「我這天也出班」。
  3. 依順位挑女孩：從名單點「＋」排進來，排越前面越先被邀請。
    時薪會自動帶入你上次和她合作的金額。
  4. 送出後，系統照順位發邀請；人數滿了就自動停止。

幾個好用的開關

  • 直接加入：已經私下談好的人，按這個就算確認。
  • 急件：時間很趕？同時邀請所有候補。
  • 鄰家女孩：團隊外的幫手，直接算進人數，不會收到通知。

之後到「我的火柴」可以加人、改時間、改日期、換人代班，或熄滅火柴。出班前 3 天和前一天 18:00 還缺人的話，系統會用 LINE 提醒你。

常見問題

收不到 LINE 邀請卡？

確認有加「賣女孩的小火柴」好友，而且沒有封鎖它。邀請也會出現在 App 的「我的班」和右上角的鈴鐺裡。

打不開、一直轉圈圈？

先把 LINE 更新到最新版，再從 LINE 裡重新打開。還是不行的話，截圖給管理者。

Android 按返回鍵，App 就關掉了？

這是正常的。請用畫面下方的按鈕切換頁面。關掉後從聊天室的橘色按鈕再打開就好。

可以用電腦開嗎？

建議用手機的 LINE 開，畫面是為手機設計的。

別人看得到我的時薪或野放嗎？

看不到。時薪只有你和那根火柴看得到；野放在其他夥伴的月曆上顯示為「沒空」。

按錯了怎麼辦？

填班隨時可以改。邀請按錯了，請直接跟火柴說，火柴可以調整。
